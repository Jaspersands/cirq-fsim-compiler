How this page computes its numbers
  • Template. Lk = (Rz·Rx·Rz) ⊗ (Rz·Rx·Rz) with 6 angles; FSim(θ,φ) = [[1,0,0,0],[0,cos θ,−i sin θ,0],[0,−i sin θ,cos θ,0],[0,0,0,e−iφ]] (Cirq's convention, qubit 0 most significant).
  • Loss. 1 − |Tr(Ut†U)|²/16, invariant under global phase.
  • Optimiser. BFGS with Armijo backtracking and central-difference gradients; up to 6 restarts per stage count, the first seeded at CZ-like (0, π), √iSWAP, iSWAP and Sycamore angles when the angles are free. Python uses L-BFGS-B with JAX gradients on the same loss.
  • Native mode. The FSim angles are constants; only the 6(n+1) dressing angles are optimised — exactly the calibrated path of the Python package.
  • Random U(4). QR of a complex Gaussian matrix with phase correction (Haar measure), seeded so results are reproducible.
  • QASM. Generated from the actual angles; `gate fsim` is defined with stdgates: exp(−iθ/2(XX+YY)) via two CNOT–Rz–CNOT conjugations, then cp(−φ).
